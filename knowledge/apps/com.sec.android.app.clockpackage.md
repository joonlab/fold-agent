# 시계 (com.sec.android.app.clockpackage)
부르는 이름: 시계, 알람, 타이머, 스톱워치, 세계시각, Clock
용도: 알람·타이머 관리. 알람 목록 확인·켜고 끄기
열면: '알람' 탭 알람 목록 화면. 상단에 '날씨를 알람 배경으로' 추천 배너가 떠 있음
화면:
상단 추천 배너: '알람 배경으로 설정' 버튼 · '추천 지우기'(id=suggest_app_bar_close).
'알람 추가'(id=menu_alarm_add, 우상단 + 버튼) · '옵션 더보기'.
알람 목록(id=alarm_list): 카드마다 시간(id=alarm_item_time)·날짜·켜기/끄기 Switch(id=alarm_onoff_switch, 설명에 '오전 HH:MM' 포함). 카드 본문 탭=편집.
하단 탭(y≈1775~1902, 설명으로만 식별): 알람 · 세계시각 · 스톱워치 · 타이머
하는 법:
- 알람 설정: set_alarm 도구 우선 → 실패 시 open_app('시계') → '알람 추가' 탭 → 시간 입력 → 저장
- 타이머 설정: set_timer 도구 우선 → 실패 시 하단 '타이머' 탭
- 특정 알람 끄기/켜기: 알람 탭 → 설명에 해당 시간('오전 01:30' 등)이 든 alarm_onoff_switch 탭
- 스톱워치 시작: 하단 '스톱워치' 탭 → (일반 지식) '시작' 버튼 탭
주의:
- 하단 탭은 텍스트 없이 설명(content-desc)으로만 식별됨
- 알람 삭제는 irreversible — 길게 눌러 삭제 등은 사용자 확인
- 알람이 많아 목록이 스크롤됨 — 원하는 시간이 안 보이면 scroll(down)
