★ 노트에 새로 정리할 땐 write_note 한 번으로, 기존 노트 끝에 덧붙일 땐 write_note mode=append(제목 그대로)로. 아래는 도구가 못 하는 편집(중간 고치기·지우기)용 실측
- 새 노트: 목록 화면의 「노트 작성」 tap
- 제목: 맨 위 「제목」(id=composer_toolbar_title)을 tap → 뜨는 제목 입력칸에 type_text. 비워 두지 않는다
- 본문: ScrollView 안의 EditText 에 type_text. 한 번만 — 넣자마자 입력칸이 글머리 기호·번호 블록으로 바뀌어 글이 안 보일 수 있다. 되풀이하면 중복된다(look 으로 확인)
- 이미지: 「삽입」(id=action_add) → 「이미지」 → 「갤러리」 → 사진 tap(목록은 최신순, 설명이 「버튼」뿐) → 위쪽 선택 칸에 파일 이름이 뜨니 맞는지 확인 → 「완료」
- 이미지는 커서 자리에 들어간다. 본문을 tap 하면 커서가 누른 자리(글 중간)로 옮겨 이미지가 엉뚱한 데 박힌다 — 커서를 잡으려고 본문을 누르지 않는다
- 항목마다 이미지를 넣으려면: 항목1 글 type_text → (back·본문 tap 없이) 바로 삽입→이미지1 → 항목2 글은 type_text 를 index 없이(커서 자리에 이어 쓰기) → 삽입→이미지2 …
- 이미지 뒤에 바로 글을 쓰면 안 들어간다(이미지가 선택된 채라 입력이 버려짐) · 빈 곳을 누르면 그 높이까지 빈 줄이 채워진다
- 「되돌리기」는 누르지 않는다 — 넣은 이미지까지 지워진다. 배치가 틀렸으면 그대로 두고 finish 에서 알린다
- 편집 중(키보드가 떠 있을 때) 화면을 손가락으로 밀면 키보드에 글자가 찍힌다 — 스크롤 전에 back 으로 키보드를 닫는다
- 저장 버튼은 없다 — 뒤로 나가면 자동 저장
