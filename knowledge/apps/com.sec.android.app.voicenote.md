# 음성 녹음 (com.sec.android.app.voicenote)
★ 녹음 → 텍스트 변환: 녹음 열기 → 「텍스트 변환 어시스트」 → 「텍스트 변환」 → 「언어 선택」 창이 한 번 더 뜬다 — 언어를 고르고 확인은 id=select_language_trans_text(앞 메뉴와 이름이 같다). 전사문(id=stt_content)은 길면 수 분 걸린다(PKM 실측 2026-09-20)
- 전사문은 화면에 보이는 만큼만 읽힌다(2분 분량이 44자) — 전문이 필요하면 오른쪽 칸 「옵션 더보기」 → 「공유」 → 「텍스트 파일」 → 공유 대상 「폴드 에이전트에게」로 받는다(파일은 UTF-16)
- 목록은 긴 이름을 자르고 오래된 항목은 화면 밖 — 스크롤 말고 위 「검색」으로 찾는다
- 펼친 화면은 2칸이라 「옵션 더보기」가 칸마다 있다 — 열어 둔 녹음의 메뉴는 오른쪽 칸 것
부르는 이름: 음성 녹음, 녹음, 녹음기, 보이스 레코더, Voice Recorder
용도: 회의·현장 녹음. 녹음 시작과 기존 녹음 재생
열면: 녹음 파일 목록 화면(분류: '기타 녹음 파일')
화면:
상단: '내비게이션 메뉴'(좌) · 분류 제목 · '검색' · '옵션 더보기'(id=more_options).
목록(id=list): 기간 헤더(이번 주/이번 달) 아래 항목마다 제목(id=listRow_title)·날짜·길이·AI 요약 문구(id=listRow_summarized)·재생 버튼(id=listRow_play_icon, 설명 '재생 <파일명>.m4a').
하단 중앙 빨간 '녹음' 버튼(id=idle_record_btn, [550,1741][697,1888])
하는 법:
- 녹음 시작: open_app('음성 녹음') → '녹음'(id=idle_record_btn) 탭 → (일반 지식) 녹음 화면에서 일시정지/정지 버튼
- 녹음 파일 찾기: 상단 '검색' 탭 → type_text(파일명, submit)
- 최근 녹음 재생: 목록 첫 항목의 재생 버튼(id=listRow_play_icon) 탭
주의:
- 녹음 제목·AI 요약 문구에 회의 내용·장소·사람 이름이 들어 있음 — 읽어주거나 기록하지 말 것
- 녹음 파일 삭제는 irreversible
- '녹음' 버튼은 즉시 녹음 시작
