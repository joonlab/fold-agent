# 캘린더 (com.samsung.android.calendar)
부르는 이름: 캘린더, 삼성 캘린더, 달력, 일정, Calendar
용도: 폰 기본 일정 조회·추가용
열면: 실행 직후 '자동 동기화 켜기' 대화상자가 앞을 가림(뒤 본문은 트리에 없음)
화면:
대화상자: 제목 '자동 동기화 켜기'(id=alertTitle), 설명 문구(id=message), 버튼 '취소'(id=button2, 좌) · '켜기'(id=button1, 우).
캘린더 본문(월간 뷰·일정 추가 버튼) 구조는 이번 덤프에서 확인 불가. (일반 지식) 우하단에 일정 추가(+) 버튼, 상단에 검색·메뉴
하는 법:
- 동기화 팝업 넘기기: '취소'(id=button2) 탭 — 켜기는 사용자 요청 시에만
- 일정 추가: 팝업 처리 → (일반 지식) '+' 일정 추가 버튼 탭 → 제목 입력 → 날짜/시간 → '저장' (일반 지식)
- 특정 날짜로 이동: open_link('content://com.android.calendar/time/{epoch밀리초}') 시도 (일반 지식)
접근성 트리: poor — 항목이 안 보이면 딥링크를 쓰거나 finish(success=false)로 사용자에게 넘긴다
주의:
- 실행 시 '자동 동기화 켜기' 팝업이 먼저 뜰 수 있음 — 먼저 처리
- 본문 트리를 확보하지 못함 — 팝업 처리 후 트리를 다시 읽고 판단
- 일정 '저장'·'삭제'·초대 수락은 irreversible
