# 갤러리 (com.sec.android.gallery3d)
★ 이번 작업에서 capture 로 찍은 사진(FoldAgent_…)을 보낼 땐 갤러리를 열지 말고 share_images 로 바로 공유 화면을. 아래는 그 밖의 사진(사용자가 찍은 것 등) 고르기·공유 실측 — 목록의 사진은 모두 설명=「버튼」뿐이라 무엇인지 트리로는 모른다 · 필요하면 look
- 목록은 최신순(「오늘」 → 「어제」…). 「최근 N장」 = 맨 위부터 N개
- 여러 장 선택: 첫 사진을 long_press → 선택 모드(체크 표시) → 나머지 사진 tap → 아래 「공유」
- 사진을 그냥 tap 하면 한 장 보기(뷰어)로 열린다 — 여기서 공유하면 한 장만 간다
- 공유 → 앱 선택 창(android.intentresolver) → 카카오톡 등. 카카오톡 공유 화면 요령은 카카오톡 [앱 요령]
부르는 이름: 갤러리, 사진, 사진첩, 앨범, Gallery
용도: 사진·동영상 열람. 방금 찍은 사진 확인·검색·공유
열면: '사진' 탭 타임라인 첫 화면. 상단에 클라우드 동기화 권유 카드('나중에'/'시작하기')가 떠 있음
화면:
상단 우측: '사진 및 동영상 동기화'(id=action_cloud_sync_timeline) · '검색'(id=action_search) · '옵션 더보기'.
본문: 날짜 헤더(id=date, 오늘/어제) 아래 3열 썸네일 그리드(id=recycler_view_item, 설명='버튼'뿐이라 내용 구분 불가).
하단 탭(y≈1775~1902): 사진 · 앨범 · 컬렉션 · 메뉴.
동기화 권유 카드: '나중에'(id=cancelView) / '시작하기'(id=doneView)
하는 법:
- 최근 사진 보기: open_app('갤러리') → 하단 '사진' 탭 → 첫 썸네일(좌상단 recycler_view_item) 탭
- 사진 검색(사물·장소·인물): 상단 '검색'(id=action_search) 탭 → 입력칸에 type_text(검색어, submit)
- 앨범별 보기: 하단 '앨범' 탭 → 앨범명 탭
- 동기화 권유 카드 닫기: '나중에'(id=cancelView) 탭
접근성 트리: partial — 항목이 안 보이면 딥링크를 쓰거나 finish(success=false)로 사용자에게 넘긴다
주의:
- 썸네일이 모두 설명='버튼'으로만 나와 어떤 사진인지 트리로 구분 불가 — 위치(첫 번째/최근)로만 지시
- '시작하기'는 클라우드 동기화를 켜는 동작 — 사용자 요청 없으면 누르지 말 것
- 삭제·휴지통 이동·공유(발송)는 irreversible
