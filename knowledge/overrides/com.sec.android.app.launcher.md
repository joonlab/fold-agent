★ 폴더 만들기·여러 앱 묶기는 드래그 없이 된다(2026-09-28 펼친 화면 실측)
- 앱스 화면(홈에서 swipe up)에서 앱 아이콘 long_press → 메뉴 「앱 정보 · 선택 · 홈 화면에 추가 · 설치 삭제」. 서랍이 열리는 중에 누르면 안 먹는다 — 열린 뒤 누른다(변화 없으면 한 번 더)
- 여러 앱을 한 폴더로: 한 앱 long_press → 「선택」 → 나머지 앱 tap(체크 표시) → 위 막대 「폴더 추가」(2개 이상 골라야 켜짐) → 앱스 화면에 폴더가 생긴다(이름 칸이 뜨면 이름을 적는다)
- 그 폴더를 홈 화면에 두기: 폴더 long_press → 「홈 화면에 추가」 · 앱 하나만 홈에 두기도 같은 메뉴
- 「옵션 더보기」(정렬·페이지 정리·설정)는 폴더와 무관하다
- 선택 모드 위 막대는 id 로 누른다: multi_select_create_folder=폴더 추가 · multi_select_remove_shortcut=홈에서 삭제 — 바로 옆 multi_select_uninstall 은 설치 삭제·사용 중지
- 누른 직후 체크가 「선택 안 됨」으로 보일 수 있다(반영이 늦다) — 잠깐 뒤 다시 보고, 다시 누르지 않는다(누르면 풀린다)
- 길게 누른 팝업의 버튼은 이름으로만 누른다(좌표 짐작 금지) — 「홈에서 삭제」 옆이 「설치 삭제」, 메시지 같은 앱은 연락처(전화) 바로가기가 끼어 팝업 높이가 다르다
- 기존 폴더 안 ⊕(id=add_apps)로 넣은 앱은 원래 자리에도 남는다(복사) · 폴더 이름은 폴더를 열고 제목(id=folder_title) tap → type_text
- 빈 홈 페이지 삭제는 그 페이지 아이콘이 0개인지 확인한 뒤에만(아이콘이 있으면 같이 사라진다)
